# Numbers
1. Integer and Float

```jsx
int_1 = 1                            -- integer 1
float_1 = 1.1                        -- float 1.1

print(int_1); print(float_1)
1
1.1
```

1. Hex — `0xa`  - represent 8 binary
    
    It starts with `0x`. `0xa` means `10` in decimal. This is very important for security — memory addresses, shellcode, color codes, everything is in hex. `0xFF`, `0x41` — all of this is hex.
    
    ```jsx
    hex_1 = 0xa
    
    print(hex_1)
    10
    
    print(type(hex_1))
    <class 'int'>
    ```
    
2. **Octal — `0o10`** - represent 16 binary
    
    It starts with `0o`. `0o10` means `8` in decimal. It is used in Linux file permissions — remember `chmod 755`? That is octal. Knowing this much is enough.
    
    ```jsx
    octal_1 = 0o10
    
    print (octal_1)
    8
    
    print(type(octal_1))
    <class 'int'>
    ```
    
    ```jsx
    print(1 + 0x1 + 0o1)         -- (whole number + hex + octal)
    3
    ```
