OPERATOR

- **`and` → If any one operand is `False`, the result is `False`.**
- **`or` → If any one operand is `True`, the result is `True`.**

```python
print(10 > 5 and 10 < 5)
print(10 > 5 or 10 < 5)

False
True
```
