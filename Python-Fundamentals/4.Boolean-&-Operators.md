Boolean in Python is True or False 

```python
valid = True
not_valid = False

print(valid)
print(not_valid)
True
False

print(valid == True)               -- '==' means equal to
print(not_valid == True)
True
False

print(valid != True)               -- '!=' means not equal to
print(not_valid != True)
False
True

print(not valid)                  -- we can use also use 'not'
print(not not_valid)                 for not equal
False
True
```
